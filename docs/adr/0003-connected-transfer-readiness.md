# Connected transfers require verified browser pairs

Browser Bridge will coordinate local transfers after one-time browser setup, using graceful quit/reopen around verified backups and additive imports. All eleven browsers stay visible, but automatic Transfer requires real end-to-end checks for the selected pair; guided fallback remains available otherwise. This trades a smaller verified automatic surface for recoverable migrations rather than treating browser-family ancestry as proof. Free local installation remains the distribution path; no paid developer enrollment is authorized.
