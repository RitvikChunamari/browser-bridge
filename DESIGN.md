# Browser Bridge

Native Mac conventions remain the visual authority. Operate mode: reusable manager, source/destination selectors, sidebar navigation, system typography and native controls. Forest green is the action accent. The source-to-destination capability map is the signature; statuses always include text. Dense content scrolls. Native focus, VoiceOver and system appearance remain available. No motion is needed.

The original logo joins two simplified browser windows through a central bridge. Canonical vector artwork is `Assets/Brand/logo.svg`; `logo-mono.svg` supports inherited ink color. `scripts/brand.swift` generates transparent PNG, white mark, green Mac icon and ICNS assets locally. Use the mark intact with clear surrounding space; do not substitute vendor browser logos or add gradients/shadows.

The main workflow stays code-led and native. Demo data is visibly labeled and cannot export. Helper pages inherit the restrained green/neutral system and support narrow widths, focus rings and dark appearance.
