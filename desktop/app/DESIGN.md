# Browser Bridge desktop surface

Operate mode. Preserve the connected-window mark and forest/lime color roles from the established product website while carrying the Mac app's task hierarchy into Windows/Linux: left navigation, source/destination route, category choices, retained backup folder and a single primary Transfer action. System sans-serif typography serves controls and data. No new illustration, decorative motion or display font is needed.

The primary scene is a person moving browsers on their own desktop. A dark forest surface matches the chosen product world, with pale readable text and a lime primary action; warnings and errors use text as well as color. Empty states explain setup, unknown routes offer guided packages, and the sensitive-data step never implies that cookie copying proves authentication. Production readiness comes from the engine, never a selector change or synthetic preview.

Layout collapses the navigation and route fields at narrow sizes. Native Tauri dialogs select local paths. Focus rings, skip navigation, semantic labels, normal buttons and a protective rollback dialog preserve familiar keyboard behavior. The browser preview is explicitly synthetic and cannot export or migrate data.
