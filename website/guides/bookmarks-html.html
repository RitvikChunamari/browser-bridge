Import and export bookmarks with HTML

Use a portable bookmarks HTML file on Mac when you need links and folders rather than live tabs or browser-specific workspaces.

A bookmarks HTML file is a practical common format when you mainly need saved links and folders. It is also a useful fallback when a connected route is unavailable. It does not preserve a full browser session: tabs, pin state, cookies, passwords and native workspace behavior are separate concerns.

Export the saved links

In Chrome, open the bookmark manager and use its export action to save bookmarks as HTML. Other browsers offer their own bookmark export controls. Follow the source browser’s official instructions and save the file somewhere private. The file can reveal personal browsing interests even though it contains no active login session.

Import with the destination’s tools

  1. Keep an untouched copy of the exported HTML file.
  2. In Chrome, use the bookmarks-and-settings import flow, choose the file and complete the import. Existing bookmarks may affect where imported links appear.
  3. In Firefox, use its import workflow and choose the available file or browser source appropriate to your case. Review the selected categories rather than accepting assumptions.
  4. Safari can import HTML bookmarks exported by supported browsers. The exact menu wording depends on the macOS version; follow Apple’s guide for your installed version.
  5. Inspect several links and folder levels before deleting the source export or changing the original profile.

Use HTML with Browser Bridge

Attach a bookmark HTML file as portable input when you want to transfer only that exported collection. Portable-input mode backs up the chosen input; it does not secretly create a complete backup of the original browser profile. Choose the destination, read the preview and follow the guided import instructions in the resulting package.

Keep expectations specific: bookmark folders can stand in for a collection of workspace URLs, but a folder is not a native Space, Essential or tab group. If your goal includes live tabs or history, inspect the route’s category support and consider a full profile export instead. Imported bookmarks can also produce duplicates if you repeatedly use unrelated import sessions.

What the beta can honestly promise

Browser Bridge is free, MIT licensed and local. The universal Mac app requires macOS 14 or later and contains Apple silicon and Intel binaries. Intel runtime has not been verified; Intel transfers remain guided. Automatic transfer is verified only for Chrome 156.0.8078.48 → Brave 156.1.98.60 on Apple silicon, after one-time connector and backup-folder setup. Other versions, directions and browser pairs remain guided.

Passwords, passkeys and active cookie sessions do not transfer automatically. Use the destination browser’s own import tools for sensitive credentials. Keep exports private and remove temporary credential files when finished. Exact native Spaces, Essentials, Favorites and extension-state parity is not promised. A profile backup is a recovery archive, not a promise another browser can read every file inside it.
