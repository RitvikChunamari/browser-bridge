Move from Zen to Dia on Mac

A guided Zen-to-Dia migration with backups, bookmarks, tabs and honest limits for Essentials, folders and spaces.

Zen and Dia organize browsing differently. Browser Bridge can help preserve the source and prepare a target-specific package, but Zen → Dia is a guided route in this beta. It has not passed the app’s full automatic lifecycle gate. Do not interpret a tab or folder export as proof that Dia has recreated Zen’s sidebar model.

Preserve Zen first

  1. Choose the Zen profile you actually use. Inspect the preview for tabs, bookmarks, folders and spaces before creating an export.
  2. Close Zen normally when the backup workflow asks. If an unsaved-work dialog appears, handle it yourself; the app must not force-quit the browser.
  3. Create a package with a checksummed local source backup. If you add a live capture, confirm that it belongs to the intended profile and represents the browsing state you want to move.
  4. Choose Dia as the destination and follow the package’s Chromium helper or portable-file instructions. Review permissions before installing a local helper.

What happens to Essentials and spaces?

Zen Essentials, pinned tabs, folders and spaces do not have guaranteed one-to-one counterparts in Dia. Supported URLs and organization may be represented as portable folders or tab groups; native-only metadata may remain in the archive. Browser APIs may expose less than Zen’s sidebar shows. Read the preview and transfer report rather than assuming identical names mean identical behavior.

Review a meaningful sample

Check one item from each space, several nested folders, a pinned item and an Essential you rely on daily. Check duplicate-looking links before removing anything. Keep your original Zen profile intact until you have rebuilt any destination-specific organization and verified important pages. Passwords, passkeys, logged-in sessions and incompatible extensions need their own migration path.

If tabs or sidebar metadata cannot be applied, bookmark HTML is a useful link-preservation fallback. It preserves a portable collection of URLs and folders, not live pin state or the complete workspace experience.

What the beta can honestly promise

Browser Bridge is free, MIT licensed and local. The universal Mac app requires macOS 14 or later and contains Apple silicon and Intel binaries. Intel runtime has not been verified; Intel transfers remain guided. Automatic transfer is verified only for Chrome 156.0.8078.48 → Brave 156.1.98.60 on Apple silicon, after one-time connector and backup-folder setup. Other versions, directions and browser pairs remain guided.

Passwords, passkeys and active cookie sessions do not transfer automatically. Use the destination browser’s own import tools for sensitive credentials. Keep exports private and remove temporary credential files when finished. Exact native Spaces, Essentials, Favorites and extension-state parity is not promised. A profile backup is a recovery archive, not a promise another browser can read every file inside it.
