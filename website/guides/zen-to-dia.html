Move from Zen to Dia on Mac

Direct 1-Click and guided Zen-to-Dia migration with local backups, multi-space mapping, pinned Essentials across every space, nested folders, and full browsing history.

Zen and Dia organize browsing around workspaces, Essentials, and vertical sidebars. In Browser Bridge v0.4.0, the 1-Click Direct Migrator (`OneClickMigrator`) and CLI (`bridge-migrate zen dia`) read Zen's SQLite (`places.sqlite`) and compressed LZ4 session files (`mozLz40`) without file-lock conflicts, automatically map Zen workspaces to individual Dia Chromium profiles, propagate Zen's global Essentials into every Dia space, and inject complete Chromium v70 browsing history.

Preserve Zen first

  1. Choose the Zen profile you actually use. Inspect the live inventory preview for bookmarks, open tabs, nested folders, spaces, and history items before migrating.
  2. In the native macOS app (`Transfer` pane), select **Zen** as Source Browser and **Dia** as Destination Browser. Browser Bridge automatically creates a pre-migration backup of all Dia profiles and SQLite WAL/SHM journals before making any changes.
  3. If you prefer a portable archive package, you can also create a checksummed local backup package under the guided workflow.
  4. When **Reopen Dia when finished** is enabled, Browser Bridge launches Dia and uses native AppleScript automation (`syncDiaLiveSpaces`) to pin your Essentials and workspace pins directly as compact sidebar tiles in each space.

What happens to Essentials, spaces, and history?

In Zen Browser, Essentials are global pinned favorites that appear across every workspace. Browser Bridge v0.4.0 preserves this exact model in Dia: all Zen Essentials are placed in every Dia space (both on the bookmarks bar and inside `⭐ Essentials` / `⭐ Pinned Favorites` folders) and pinned into the top grid of each Dia profile's sidebar with canonical URL deduplication so login redirects never create duplicate tiles.

Each Zen space (`Personal`, `School`, `Work`, etc.) is mapped to its corresponding Dia profile (`Profile 9` / `Default`, `Profile 1`, `Profile 2`, etc.), retaining its own `📌 Pinned Tabs`, recursive nested subfolders, and open tabs. Full browsing history from `moz_places` and `moz_historyvisits` is converted to Chromium's Windows FileTime microsecond schema across all Dia profiles.

Review a meaningful sample

Check one item from each space, several nested folders, a pinned item and an Essential you rely on daily. Check duplicate-looking links before removing anything. Keep your original Zen profile intact until you have verified important pages. Instant 1-click rollback (`Revert…`) restores Dia's exact pre-migration state anytime. Passwords, passkeys, logged-in sessions and incompatible extensions still need their own migration path.

If tabs or sidebar metadata cannot be applied in a custom setup, bookmark HTML remains available as a link-preservation fallback. It preserves a portable collection of URLs and folders.

What the beta can honestly promise

Browser Bridge is free, MIT licensed and local. The universal Mac app requires macOS 14 or later and contains Apple silicon and Intel binaries. Intel runtime has not been verified; Intel transfers remain guided. Automatic connected connector verification covers Chrome 156.0.8078.48 → Brave 156.1.98.60 on Apple silicon, while 1-Click Direct Profile Migration supports local profile injection and instant rollback across macOS browsers. Other versions, directions and browser pairs remain guided.

Passwords, passkeys and active cookie sessions do not transfer automatically. Use the destination browser’s own import tools for sensitive credentials. Keep exports private and remove temporary credential files when finished. A profile backup is a recovery archive, not a promise another browser can read every file inside it.
